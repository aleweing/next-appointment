# Especificación del proyecto

Resumen:
- Nombre: next-appointment
- Propósito: Aplicación para gestionar y programar próximas citas.

Objetivos principales:
- Permitir a los usuarios crear, editar y borrar citas.
- Mostrar próximas citas ordenadas por fecha.
- Notificaciones/reminders (opcional).

Características y requisitos:
- Interfaz web responsiva.
- Persistencia de datos (localStorage o API backend).
- Validación de entradas (fecha/hora, título).

Criterios de aceptación:
- Un usuario puede crear una cita con título, fecha y hora.
- Las citas se muestran en orden cronológico.
- Las citas pueden editarse y eliminarse desde la UI.

Notas:
- Esta especificación es inicial y debe ampliarse con diagramas y modelos de datos cuando avancemos.
